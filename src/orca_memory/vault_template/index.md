# Orca vault

This is a portable starter layout for an Orca vault. Its rules are tentative;
the Owner may revise them. Read [`System/rules.md`](System/rules.md) before
adding or changing content.

## Canonical destinations

- [`Knowledge/`](Knowledge/) for accepted general knowledge.
- [`Projects/`](Projects/) for accepted project notes.
- [`People/`](People/) for accepted people notes.
- [`Daily/`](Daily/) for accepted daily notes.
- [`System/Context/`](System/Context/) for accepted vault context.

## Pending intake

- [`Inbox/Raw/`](Inbox/Raw/) for supplied sources awaiting review.
- [`Inbox/Notes/`](Inbox/Notes/) for quick thoughts, ideas, and reminders awaiting review.

## System areas

- [`System/`](System/) contains local rules, workflows, and context navigation.
- [`System/Orca Memory/`](System/Orca%20Memory/) contains noncanonical runtime memory artifacts and policy.
- [`Archive/`](Archive/) is an optional place for retained sources and notes.
