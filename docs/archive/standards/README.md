# Historical layout standards

This directory preserves standards and transition material that once governed
Orca's project organization. They are historical and do not define the current
PLS 0.3 layout.

- [`PDS-0.2.md`](PDS-0.2.md) is the former Project Documentation Standard
  baseline.
- [`pds-migration/`](../pds-migration/README.md) records Orca's completed PDS
  migration.

The PDS baseline was moved from the repository root without rewriting its
substance. Project-relative example links inside that historical document may
therefore reflect its former root location.
