# ADR-0003: Graduate canonical apply by category

Canonical apply is implemented behind a separate guarded seam and begins disabled. Automation graduates per disposition category through approval, shadow, and bounded canary evidence because routine low-risk changes can become automatic while sensitive, contradictory, destructive, structural, and governance-changing work retains human authority.
